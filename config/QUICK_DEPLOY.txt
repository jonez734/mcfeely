ONE-LINE SETUP (if already installed)
═════════════════════════════════════════════════════════════════════════════

cd ./mistermcfeely/config && \
sudo cp cyrus.conf imapd.conf imapd.annotations /etc/postoffice/ && \
sudo cp mcfeely-notify /usr/local/bin/ && \
sudo chmod 755 /usr/local/bin/mcfeely-notify && \
sudo systemctl restart cyrus-imapd


STEP-BY-STEP DEPLOYMENT
═════════════════════════════════════════════════════════════════════════════

STEP 1: Install Cyrus IMAPd (if not already installed)
───────────────────────────────────────────────────────

  Fedora/RHEL:
  sudo dnf install cyrus-imapd cyrus-imapd-utils cyrus-sasl cyrus-sasl-plain

  Debian/Ubuntu:
  sudo apt-get install cyrus-imapd cyrus-sasl


STEP 2: Deploy Configuration Files
───────────────────────────────────

  cd ./mistermcfeely/config
  
  sudo cp cyrus.conf /etc/postoffice/cyrus.conf
  sudo cp imapd.conf /etc/postoffice/imapd.conf
  sudo cp imapd.annotations /etc/postoffice/imapd.annotations
  
  Verify permissions:
  ls -la /etc/postoffice/cyrus.conf /etc/postoffice/imapd.conf /etc/postoffice/imapd.annotations
  # Should show: -rw-r--r-- root:root


STEP 3: Deploy Event Handler Script
─────────────────────────────────────

  sudo cp mcfeely-notify /usr/local/bin/
  sudo chmod 755 /usr/local/bin/mcfeely-notify
  
  Verify:
  ls -la /usr/local/bin/mcfeely-notify
  # Should show: -rwxr-xr-x


STEP 4: Create Required Directories
──────────────────────────────────────

  sudo mkdir -p /var/lib/imap /var/spool/imap
  sudo chown -R cyrus:cyrus /var/lib/imap /var/spool/imap
  sudo chmod 750 /var/lib/imap /var/spool/imap


STEP 5: Initialize Cyrus Databases
──────────────────────────────────

  sudo /usr/lib/cyrus-imapd/tools/mkimap
  
  Verify:
  ls -la /var/lib/imap/*.db*


STEP 6: Start Cyrus Service
──────────────────────────

  sudo systemctl enable cyrus-imapd
  sudo systemctl start cyrus-imapd
  
  Check status:
  sudo systemctl status cyrus-imapd


STEP 7: Verify Deployment
──────────────────────────

  # Check service is running
  systemctl is-active cyrus-imapd

  # Check event handler path is configured
  grep event_notifier_path /etc/postoffice/imapd.conf

  # Check event handler is external
  grep "^event_notifier:" /etc/imapd.conf

  # View recent logs
  journalctl -u cyrus-imapd -n 20


STEP 8: Configure Database Notification Rules
───────────────────────────────────────────────

  In your PostgreSQL/MySQL database:

  -- Enable notifications for shared mailboxes
  INSERT INTO postoffice.__mailbox
  (mailbox_name, enable_new_message_events, imap_poll_interval_seconds)
     -- writes go to the underlying table; reads use postoffice.mailbox (view)
  VALUES ('shared/%', TRUE, 5);

  -- Route events to admin
  INSERT INTO postoffice.message_routing
  (mailbox_name, event_type, actor_moniker, recipient_moniker, urgency)
  VALUES ('shared/%', '*', NULL, 'admin', 'ROUTINE');


STEP 9: Test the Integration
─────────────────────────────

  # Create test mailbox
  sudo cyradm -u cyrus localhost <<'CYRADM'
  cm shared/test@localhost
  quit
  CYRADM

  # Watch logs for events
  journalctl -u cyrus-imapd -f | grep mcfeely-notify

  # Send test message (in another terminal)
  echo "Test message" | mail -s "Test" shared-test@localhost

  # Check event was logged
  journalctl -u cyrus-imapd | grep "mcfeely-notify: Event:"

  ✓ /var/lib/imap/annotation.db* files exist


TROUBLESHOOTING QUICK CHECKS
═════════════════════════════════════════════════════════════════════════════

  Service won't start:
  → sudo journalctl -u cyrus-imapd | tail -30
  → Look for configuration errors in imapd.conf

  Event handler not called:
  → sudo grep event_notifier /etc/postoffice/imapd.conf
  → Restart service: sudo systemctl restart cyrus-imapd
  → Send message and check: journalctl -u cyrus-imapd | grep mcfeely

  Annotation not working:
  → Check: ls -la /var/lib/imap/annotation.db*
  → If missing: run /usr/lib/cyrus-imapd/tools/mkimap again

  Permission errors:
  → Check: ls -la /var/lib/imap
  → Should be: drwxr-x--- cyrus:cyrus
  → Fix: sudo chown -R cyrus:cyrus /var/lib/imap

  Port conflicts:
  → Check: netstat -tlnp | grep -E ':143|:993|:4190'
  → If ports in use: stop other IMAP services


COMMON CUSTOMIZATIONS
═════════════════════════════════════════════════════════════════════════════

  Change admin user:
  In /etc/postoffice/imapd.conf:
    admins: cyrus        → admins: mailops

  Change max connections:
  In /etc/postoffice/imapd.conf:
    maxchild: 100        → maxchild: 200

  Change message size limit:
  In /etc/postoffice/imapd.conf:
    maxmessagesize: 102400  → maxmessagesize: 524288000

  Change SASL mechanism:
  In /etc/postoffice/imapd.conf:
    sasl_mech_list: PLAIN LOGIN  → sasl_mech_list: DIGEST-MD5 PLAIN

WHAT HAPPENS WHEN YOU SEND A MESSAGE
═════════════════════════════════════════════════════════════════════════════

  1. Message arrives at Postfix
  2. Postfix delivers via LMTP to Cyrus
  3. Cyrus stores in /var/spool/imap/shared/test@localhost/
  4. imapd processes the message
  5. notifyd detects new message
  6. notifyd calls mcfeely-notify script
  7. mcfeely-notify parses RFC 5423 event
  8. mcfeely-notify calls message_client.fire_event()
  9. message_client checks postoffice.mailbox (per-member: mailbox_member)
  10. message_client loads message_routing rules
  11. For each matching rule, inserts into engine.__notify
  12. External systems (email, chat, dashboard) consume event


PORTS USED
═════════════════════════════════════════════════════════════════════════════

  143   - IMAP (plaintext)
  993   - IMAPS (TLS encrypted)
  4190  - Sieve (email filtering)
  (24)  - LMTP (internal, Unix socket by default)

EMERGENCY REVERT
═════════════════════════════════════════════════════════════════════════════

  If something goes wrong, you can revert to log-based events:

  1. Edit /etc/postoffice/imapd.conf:
     Change: event_notifier: external
     Back to: event_notifier: log

  2. Restart service:
     sudo systemctl restart cyrus-imapd

  3. Check logs (events now in syslog instead):
     journalctl -u cyrus-imapd


SUCCESS INDICATORS
═════════════════════════════════════════════════════════════════════════════

  When everything is working:

  ✓ systemctl status cyrus-imapd shows "active (running)"
  ✓ netstat shows ports 143, 993, 4190 listening
  ✓ /var/lib/imap/*.db* files exist and are recent
  ✓ journalctl shows no errors from cyrus-imapd
  ✓ Messages sent to shared mailboxes trigger logs in journalctl
  ✓ mcfeely-notify script logs appear: "mcfeely-notify: Event:"
  ✓ message_client.fire_event() is called for shared/* mailboxes
