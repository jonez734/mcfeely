QUICK START
================================================================================

1. Review documentation:
   $ less README.md

2. Install packages:
   # On Fedora/RHEL:
   sudo dnf install cyrus-imapd cyrus-imapd-utils cyrus-sasl cyrus-sasl-plain

   # On Debian/Ubuntu:
   sudo apt-get install cyrus-imapd cyrus-sasl

3. Deploy configuration:
   sudo cp cyrus.conf /etc/postoffice/cyrus.conf
   sudo cp imapd.conf /etc/postoffice/imapd.conf
   sudo cp imapd.annotations /etc/postoffice/imapd.annotations

4. Initialize directories:
   sudo mkdir -p /var/lib/imap /var/spool/imap
   sudo chown -R cyrus:cyrus /var/lib/imap /var/spool/imap
   sudo /usr/lib/cyrus-imapd/tools/mkimap

5. Start service:
   sudo systemctl enable cyrus-imapd
   sudo systemctl start cyrus-imapd

For detailed instructions, see CYRUS_SETUP.md

⚡ UPDATED: External Event Handler Integration

The imapd.conf has been UPDATED to use external notifier for mistermcfeely:

  event_notifier: external

This integrates Cyrus's built-in notifyd with mistermcfeely's message_client.py,
enabling real-time event routing to bbsengine6.__notify.

📝 DEPLOYMENT OF EVENT HANDLER

After deploying Cyrus configuration, install the event handler script:

  1. Copy the event handler script:
     sudo cp ./mistermcfeely/config/mcfeely-notify /usr/local/bin/
     sudo chmod 755 /usr/local/bin/mcfeely-notify

  2. Verify installation:
     ls -la /usr/local/bin/mcfeely-notify

  3. Check Cyrus config has path configured:
     grep event_notifier_path /etc/postoffice/imapd.conf
     # Should show: event_notifier_path: /usr/local/bin/mcfeely-notify

  4. Restart Cyrus to enable external notifier:
     sudo systemctl restart cyrus-imapd

  5. Monitor events:
     journalctl -u cyrus-imapd -f | grep mcfeely-notify

🔄 EVENT FLOW WITH EXTERNAL NOTIFIER

  Cyrus Mailbox Event
        ↓
  notifyd detects change
        ↓
  Calls: /usr/local/bin/mcfeely-notify -c <class> -u <user> -m <mailbox> -p <priority>
        ↓
  mcfeely-notify script parses event
        ↓
  Filters shared mailboxes only
        ↓
  Imports mistermcfeely.message_client
        ↓
  Converts Cyrus event class to mistermcfeely event type
        ↓
  Fires event to bbsengine6.__notify via message_client.fire_event()
        ↓
  Routes to recipients based on postoffice.message_routing
        ↓
  Other systems consume notifications (email, chat, webhooks, etc.)

📋 MISTERMCFEELY NOTIFYD_CLIENT INTEGRATION

The mcfeely-notify script bridges Cyrus events to your existing code:

  File: ./mistermcfeely/src/postoffice/message_client.py
  
  Key Functions:
    • fire_event() - Routes events to recipients
    • is_event_enabled() - Checks notification config
    • get_routing_rules() - Loads routing from database
    • obfuscate_moniker() - HMAC hashing for privacy
    • _fire_event_fallback() - Graceful degradation

Event Types Supported:
    • message-new - New message arrives
    • message-deleted - Message expunged
    • message-moved - Message moved to another mailbox
    • message-flagged - Message flags changed (includes claims)
    • mailbox-created - Shared mailbox created
    • mailbox-deleted - Shared mailbox deleted
    • mailbox-renamed - Shared mailbox renamed

🎯 EVENT HANDLER SCRIPT DETAILS

Location: /usr/local/bin/mcfeely-notify
Purpose: Bridge between Cyrus notifyd and mistermcfeely event routing

How it works:
  1. Receives RFC 5423 event from Cyrus notifyd
  2. Parses command-line arguments (-c, -u, -m, -p)
  3. Reads JSON event data from stdin
  4. Filters events (only processes shared/* mailboxes)
  5. Converts Cyrus event class to mistermcfeely event type
  6. Calls mistermcfeely.message_client.fire_event()
  7. Routes to recipients via bbsengine6.__notify
  8. Logs all events to syslog

Error Handling:
  • Gracefully handles missing mistermcfeely (logs warning, continues)
  • Validates JSON event data
  • Logs errors to syslog without crashing notifyd
